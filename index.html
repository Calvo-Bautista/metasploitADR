Un módulo es una pieza del framework. Un encoder no garantiza evadir un antivirus.

Exploit y payload no son lo mismo. El exploit usa la vulnerabilidad; el payload define qué se ejecuta después. Meterpreter es una opción de sesión interactiva, no el resultado de todos los exploits. Auxiliary recopila información o comprueba fallas, Post analiza el acceso. Encoder adapta el payload a restricciones técnicas. NOP es especializado en ciertos exploits de memoria. Evasion permite evaluar defensas en un contexto autorizado. Algunas vulnerabilidades ya ofrecen una shell: no todos los módulos inyectan un payload nuevo. Duración: 2 minutos.

03 / CASO DE USO REAL

EternalBlue.
Una lección de 2017.

BOLETÍN DE SEGURIDADMS17-010SMBv1 · Windows · ejecución remota
14 MARZO / 2017

El parche ya existía.

Microsoft publica MS17-010 para corregir fallas en SMB.

12 MAYO / 2017

WannaCry se propaga.

El ransomware aprovecha equipos que seguían sin actualizar.

USO DEFENSIVO

Validar y corregir.

Metasploit ayuda a comprobar exposición en sistemas autorizados.

LA LECCIÓN

Un parche disponible no protege un sistema si no se instala.

MS17-010 es un boletín que corrige varias vulnerabilidades, no el nombre de una única CVE. EternalBlue se asocia especialmente con CVE-2017-0144. WannaCry usó esta técnica para propagarse mediante SMB entre equipos vulnerables. No fue causado por Metasploit ni necesitó Metasploit para propagarse. El framework tiene módulos de detección y explotación relacionados que permiten validar el riesgo en un entorno autorizado. La demo que sigue utiliza otra vulnerabilidad, vsftpd, por ser más simple para el laboratorio. Duración: 2 minutos.

De un proyecto
a un ecosistema.

Hoy

Comunidad abierta

Módulos y contribuciones para investigación y auditorías.

No es una colección estática de exploits. Es una plataforma para desarrollar y compartir conocimiento.

H. D. Moore inició Metasploit en 2003. Las primeras versiones se escribieron en Perl. Metasploit 3, lanzado en 2007, fue reescrito en Ruby. Rapid7 adquirió el proyecto en 2009; el Framework siguió siendo open source. Por eso 2011 no debe presentarse como el inicio del código abierto. La comunidad contribuye módulos, correcciones y documentación. Existen productos comerciales relacionados, pero no son lo mismo que el Framework. Duración: 1:30.

vsftpd: reemplazar la distribución comprometida. EternalBlue: aplicar MS17-010 y deshabilitar SMBv1.

Defensa en capas: ninguna medida sola garantiza seguridad. En vsftpd hay que reemplazar el artefacto comprometido por software actual de una fuente confiable y verificar firmas o hashes publicados por un canal confiable. No basta con afirmar “2.3.5+” como política actual. Si ya hubo una intrusión, investigar y reconstruir según corresponda. En EternalBlue, instalar las actualizaciones y quitar SMBv1; no exponer SMB a Internet. Los puertos y comportamientos anómalos ayudan a detectar, pero bloquear 6200 no erradica la backdoor. Mínimo privilegio reduce daños, no neutraliza un binario malicioso. Duración: 2 minutos.
